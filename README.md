# Cactus Hotels, Gombe — Website

Official presentation website for Cactus Hotels, Gombe ("Your comfort, our commitment").

Static single-page site: rooms and rates, amenities, photo gallery, Google Maps location and direct call/WhatsApp/email booking actions. Built with vanilla HTML, CSS and JavaScript plus Swiper and GLightbox via CDN. All photographs are the hotel's own.

## Hosting
GitHub Pages serves the `main` branch root. To move this site to another account (e.g. the hotel's own), transfer the repository in GitHub Settings, then re-enable Pages there, or push this content to the new account and point the domain.

## Content sources
Rates, room counts, amenities, check-in policy and contacts come from the hotel's own documents (room tariff, room standards guide, guest T&Cs, letterhead). No content is fabricated.
